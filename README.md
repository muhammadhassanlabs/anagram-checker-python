# Anagram Checker in Python

A simple Python program that checks whether two texts are **anagrams** of each other.

##  About the Project

An anagram is a word or phrase that can be rearranged to form another word or phrase using the same letters.

For example:

* `listen` → `silent` ✅
* `triangle` → `integral` ✅
* `hello` → `world` ❌

This project takes two texts from the user, removes spaces, sorts their characters, and compares the results to determine whether they are anagrams.

##  Features

* Takes two texts as user input
* Converts text to lowercase
* Ignores spaces
* Uses Python's `sorted()` function to compare characters
* Displays whether the texts are anagrams

##  Technologies Used

* Python 3
* `sorted()`
* String methods
* Conditional statements
* User input

##  How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

```bash
git clone https://github.com/your-username/anagram-checker-python.git
```

3. Open the project folder:

```bash
cd anagram-checker-python
```

4. Run the program:

```bash
python anagram.py
```
